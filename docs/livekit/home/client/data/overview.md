# Realtime text & data

> 參與者之間交換文字、文件和自訂資料。

- **[Sending text](https://docs.livekit.io/home/client/data/text-streams.md)**: 使用文字流發送和接收文字數據，例如 LLM 回應或聊天訊息。

- **[Sending files & bytes](https://docs.livekit.io/home/client/data/byte-streams.md)**: 使用位元組流傳輸檔案、圖像或任何其他二進位資料。

- **[Remote method calls](https://docs.livekit.io/home/client/data/rpc.md)**: 使用 RPC 對房間中的其他參與者執行自訂方法並等待回應。

為了對單一資料包行為進行低階控制，LiveKit 還包含一個簡單的 [data packets](https://docs.livekit.io/home/client/data/packets.md) API。
