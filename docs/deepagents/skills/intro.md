# Overview

> 一種簡單、開放的格式，旨在賦予 AI Agent 新的能力和專業知識。

Agent Skills 是包含指令、腳本和資源的資料夾，代理可以發現並使用它們來更準確、更有效率地完成任務。

## Why Agent Skills?

Agents 的能力日益增強，但往往缺乏可靠完成實際工作所需的上下文資訊。Skills 透過賦予智能體存取程序性知識以及公司、團隊和使用者特定上下文資訊的權限來解決這個問題，這些知識和上下文資訊可以 {==按需加載==}。擁有特定技能的智能體可以根據正在執行的任務擴展自身能力。

- **For skill authors**: 一次性地建置 Agent 能力(capabilities)，即可部署到多個 Agent 產品。
- **For compatible agents**: 對技能的支援使最終用戶能夠為 Agents 賦予開箱即用的新功能。
- **For teams and enterprises**: 將組織知識擷取到可移植、版本控制的 package 中。

## What can Agent Skills enable?

- **Domain expertise**: 將專業知識打包成可重複使用的指令，涵蓋從法律審查流程到資料分析流程的各個面向。
- **New capabilities**: 賦予代理新的能力（例如建立簡報、建立 MCP 伺服器、分析資料集）。
- **Repeatable workflows**: 將多步驟任務轉化為一致且可稽核的工作流程。
- **Interoperability**: 在不同的技能相容代理產品中重複使用相同技能。

## Adoption

Agent Skills 由領先的人工智慧開發工具提供支援。


## Open development

Agent Skills 格式最初由 Anthropic 開發，並以開放標準的形式發布，已被越來越多的智能體產品採用。該標準歡迎更廣泛的生態系統貢獻內容。
